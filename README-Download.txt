CSE AI ALPHA TERMINAL - WINDOWS

INSTALL
1. Extract every file from this ZIP into a folder you can write to.
2. Double-click "Install Desktop Shortcut.bat" once.
3. Open "CSE AI Alpha Terminal" from your desktop. Its shortcut uses the app logo.

OLLAMA / AI
Install Ollama for Windows separately: https://ollama.com/download
The app will try to start Ollama and download the configured model the first time.
Model download requires an internet connection and can take time. Live CSE/news
features also need internet access.

YOUR DATA
The database and uploaded reports are kept in:
%LOCALAPPDATA%\CSE AI Alpha Terminal
They are not included in this download.

The app is a local informational tool. Review extracted financial values against
the source report; the app does not execute trades.
